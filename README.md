# skip-painting-site

前橋市の塗装店「スキップ」（細谷さん）のホームページ制作用リポジトリです。現在は、1ページ完結のLP（ランディングページ）のたたき台を置いています。

## 目的とコンセプト

- 最優先の目的は、電話とフォームでの問い合わせを増やすことです。
- 小規模な塗装店で、施工実績の数が少なく、更新も年に数回の想定のため、複数ページのサイトではなく1ページのLPから始めました。
- 検索流入は、ページ数が多いサイトより弱くなります。Googleビジネスプロフィール（マップ表示）の登録と、名刺・チラシからのQRコード導線を併用する前提です。
- 事例が増えたら、LPを残したまま事例ページだけ追加できます。

## ロゴ（案A）

- 太いゴシックの「SKIP」の下に、刷毛で引いたオレンジの線を入れたデザインです。
- 外壁塗装の堅実さと職人感を出すため、色は紺とオレンジの2色にしています。
  - 紺：`#14284B`
  - オレンジ：`#F28C28`
- 名刺、車のマグネット、作業着、看板に展開しやすく、小さくしても潰れにくい形を選びました。
- GPTで作った3案（A：シンプル信頼型、B：スキップする動き型、C：家＋刷毛型）から、仮でAを採用しています。
- 文字はアウトライン化しているため、フォントがなくても同じ形で表示されます。
- 使い始める前に、前橋周辺の同業に似たロゴがないか、検索で確認してください。

## LPの構成

上から次の順です。

1. ヘッダー（ロゴ、電話番号）
2. ファーストビュー（キャッチコピー、電話とフォームへのボタン）
3. 症状から探す（5つの症状を選ぶと、塗り替えの目安を表示）
4. スキップが選ばれる理由（3点）
5. 施工事例（ビフォーアフター写真の枠）
6. 対応している工事
7. ご相談から完成までの流れ（5ステップ）
8. 料金の目安
9. 代表あいさつ
10. 会社情報
11. お問い合わせ（電話とフォーム）

スマホで見られることを優先し、画面下に電話と無料見積のボタンを固定しています。参考にしたサイトから、問いかけ型の見出し、見出し上の英字ラベル、症状から探す導線を取り入れました。

## 仮の内容（差し替えが必要な箇所）

`index.html` の次の部分は、すべて仮の内容です。画面上部にも「確認用のたたき台」の帯を出しています。

- 電話番号（`027-000-0000`）、受付時間、営業時間
- 写真（メイン、施工事例のビフォーアフター、代表）
- 料金の目安（`○○万円〜` の部分）
- 「選ばれる理由」と代表あいさつの文面
- 会社情報（フルネーム、所在地の番地、対応エリアの範囲）
- 対応している工事の範囲（内装、ベランダなど）
- お問い合わせフォーム：見た目のみで、送信されません。送信先は未定です。
